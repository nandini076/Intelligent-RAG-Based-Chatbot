# Intelligent RAG-Based Chatbot

## Project Overview
An intelligent RAG chatbot that answers questions from PDF documents and provides source references.

## Key Features
- PDF loading and text extraction
- Text splitting and chunking
- Hugging Face embeddings
- FAISS vector database
- Groq LLM integration
- Gradio chatbot interface
- RAGAS evaluation

## Technologies Used
Python, LangChain, Hugging Face, FAISS, Groq API, Gradio, RAGAS, Google Colab.

## Installation
Install dependencies using pip install -r requirements.txt

## API Configuration
Configure your Groq API key securely using Google Colab Secrets. Never upload API keys to GitHub.
